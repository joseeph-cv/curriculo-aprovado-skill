# Formatação no Word

Padrão visual do Currículo Aprovado. Simples de propósito: quanto menos elementos gráficos, melhor o ATS lê o arquivo.

| Item | Configuração |
|---|---|
| Papel | A4 |
| Margens | Estreitas: 1,1 cm em cima e embaixo, 1,4 cm nas laterais |
| Fonte | Arial em todo o documento, cor preta |
| Colunas | 1 (exceto a lista de habilidades, que pode ficar em 2) |
| Foto | Não usar |
| Nome | 18 pt, negrito, com uma linha (borda inferior) embaixo |
| Contatos | 2 linhas abaixo do nome: "Cidade - UF \| telefone" e "e-mail \| LinkedIn" |
| Títulos de seção | Negrito, com borda inferior |
| Corpo do texto | 11,5 pt |
| Resumo | Texto justificado |
| Cargo e formação | Linha em negrito com as datas; empresa ou instituição na linha de baixo |
| Arquivo | Salvar como `.docx` e também em PDF; nome: `Nome Completo - Currículo Atualizado` |

## Evite

- Modelos prontos com colunas laterais, ícones, barras de nível ou caixas de texto: o ATS costuma ler fora de ordem ou ignorar.
- Informações no cabeçalho ou rodapé do Word: alguns sistemas não leem essas áreas.
- Fontes decorativas ou coloridas.
- Mais de 2 páginas (para estágio e júnior, o ideal é 1).
